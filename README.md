## Maintenance and regression tests

Maintainer: Hamdy Abou El Anein — hamdy.aea@protonmail.com

Install `requirements.txt` in a virtual environment. Run `python3 -m unittest -v` from the repository root. Worker examples now cooperate with shutdown; the communication worker can be restarted without reusing a deleted QThread. The task entry ignores whitespace-only tasks. Four offscreen Qt tests cover restart, active shutdown and task input. Original chapter organization is retained.
